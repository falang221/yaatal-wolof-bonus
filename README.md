# Studio Yaatal Pro — Espace Bonus & Audio Wolof

Espace compagnon officiel du livre **« Mon Premier Cahier d'Activités Bilingue Français – Wolof (4–8 ans) »** par **Abdourahmane Ndiaye — Studio Yaatal Pro** (ISBN `9798144391009`).

## Contenu
- `downloads/pack_10_fiches_bonus_yaatal_pro.pdf` : Pack imprimable de 10 fiches bonus N&B (`8,5 × 11 po`).
- `index.html`, `styles.css`, `app.js` : Guide interactif de prononciation & explorateur des 44 mots et expressions du cahier (Chapitres 1 à 5 + Clés `X, Ñ, Ë`).
- `audio/` : Dossier prêt pour accueillir les fichiers `.mp3` natifs (voir [`audio/README.md`](./audio/README.md)).

## Déploiement Vercel
Site 100 % statique, zéro dépendance de build : il suffit d'importer ce dépôt sur Vercel.
