# Enregistrements Audio Natifs — Studio Yaatal Pro

Placez vos fichiers `.mp3` enregistrés par un(e) locuteur(trice) natif(ve) directement dans ce dossier `./audio/`, puis ajoutez leur nom de fichier dans `audio/manifest.json` (`"available": ["salamalekum.mp3", ...]`).

Tant qu'un fichier n'est pas listé dans `manifest.json`, l'application web affiche automatiquement le bandeau **« Audio natif bientôt ajouté — prononciation : [...] »** avec le découpage syllabique pour les parents, sans aucune erreur réseau.
